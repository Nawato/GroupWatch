GroupWatch - your own sound files
================================

  The addon comes with two sounds of its own: "Bruh" and "Oof". They are
  always in the sound list of every list, and they cannot be removed.

  1. Put your .ogg or .mp3 file in THIS folder.
     Any file name works, for example "BossAlert.ogg" or "heal.ogg".
     The name without the extension is what the addon shows in the sound
     list, so "BossAlert.ogg" appears as "BossAlert".
  2. RESTART the game completely. World of Warcraft only looks for new
     files while it starts up - /reload is not enough.
  3. Add the sound to the addon:
       /gw sound add BossAlert
     or pick "Add sound file..." in a list's sound menu and type the
     name. Either way the name is remembered from then on.

After that the sound is yours forever: it shows up in every list's sound
menu, and if you delete the file it is marked as missing instead of
breaking anything.

Rules
-----
  - .ogg and .mp3 both work.
  - The file must sit directly in this folder, not in a subfolder.
  - Avoid spaces and special characters in the file name.
  - Keep it short. A sound that runs longer than a second or two will
    still be playing when the next alert comes.
  - "Bruh" and "Oof" ship with the addon and cannot be removed.

Commands
--------
  /gw sound list              lists your sound files
  /gw sound add <name>        adds one (the name without extension)
  /gw sound remove <name>     removes one

Not hearing anything?
---------------------
  A sound marked "(missing file)" means the game has not seen the file
  yet: copy it in and restart the game completely, or check that the
  name is exactly the file name without its extension.

  If the sound is listed plainly (for example "BossAlert") the game
  found it, and the sound plays when a watched player joins your group.


GroupWatch - eigene Sounddateien
================================

  Das Addon bringt zwei eigene Sounds mit: "Bruh" und "Oof". Sie stehen
  dauerhaft in der Soundliste jeder Liste und lassen sich nicht entfernen.

  1. Lege deine .ogg- oder .mp3-Datei in DIESEN Ordner.
     Der Dateiname ist frei waehlbar, zum Beispiel "BossAlert.ogg" oder
     "heal.ogg". Der Name ohne Endung ist der, den das Addon in der
     Soundliste anzeigt: aus "BossAlert.ogg" wird "BossAlert".
  2. Das Spiel komplett NEU STARTEN. WoW sucht nur beim Start nach neuen
     Dateien - ein /reload reicht nicht.
  3. Den Sound im Addon eintragen:
       /gw sound add BossAlert
     oder im Soundmenue einer Liste "Sounddatei hinzufuegen..." waehlen
     und den Namen eintippen. Der Name wird danach dauerhaft gemerkt.

Danach gehoert der Sound dir: Er erscheint in der Soundliste jeder Liste,
und wenn du die Datei loeschst, wird er als fehlend markiert, statt
irgendetwas zu zerstoeren.

Regeln
------
  - .ogg und .mp3 funktionieren beide.
  - Die Datei muss direkt in diesem Ordner liegen, nicht in einem
    Unterordner.
  - Leerzeichen und Sonderzeichen im Dateinamen vermeiden.
  - Kurz halten. Ein Sound, der laenger als ein bis zwei Sekunden dauert,
    laeuft beim naechsten Alarm noch.
  - "Bruh" und "Oof" sind im Addon enthalten und nicht entfernbar.

Befehle
-------
  /gw sound list              listet deine Sounddateien auf
  /gw sound add <Name>        fuegt eine hinzu (Name ohne Endung)
  /gw sound remove <Name>     entfernt eine

Kein Ton?
---------
  Ein Sound mit "(Datei fehlt)" bedeutet, dass das Spiel die Datei noch
  nicht kennt: Kopiere sie hinein und starte das Spiel komplett neu, oder
  pruefe, ob der Name genau der Dateiname ohne Endung ist.

  Ist der Sound normal aufgefuehrt (zum Beispiel "BossAlert"), hat das
  Spiel ihn gefunden, und er laeuft, wenn ein beobachteter Spieler deiner
  Gruppe beitritt.
